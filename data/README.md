# Data setup

Download `train.csv` from the [Rossmann Store Sales competition](https://www.kaggle.com/c/rossmann-store-sales/data), then place it in this repository as either:

- `data/raw/Rossmann_train.csv`
- `data/raw/Rossmann_train.csv.gz`

The notebook reads the compressed file by default. The dataset is excluded from the public portfolio repository and must be obtained from its original source.
